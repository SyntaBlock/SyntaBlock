## 🔷 About SyntaBlock

SyntaBlock is an Oman-based software technology initiative focused on intelligent development tools, visual programming, source code analysis, and AI-assisted software engineering.

## 🧩 Featured Project — SyntaBlock Studio

An integrated development environment **under active development**, designed to combine traditional source editing, visual blocks, and intelligent engineering tools.

## 🛠️ Technology Focus

**Core stack**

- Rust backend engineering
- Tauri desktop architecture
- Svelte + Vite frontend (TypeScript)

**Engineering areas in progress**

- Blockly integration and bidirectional code ⇄ blocks transformation
- Abstract Syntax Tree (AST) analysis
- AI agent workflows
- Mathematical analysis engines
- Cross-platform development

> Features listed above describe the project's direction. Capabilities are announced only once they are implemented and verified.
